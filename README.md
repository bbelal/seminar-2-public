# Seminar 2: Logistic Regression

How to model the probability of a class given the features, how to fit the model by maximum likelihood, and what happens on real data: decision boundaries, curved boundaries, and overfitting.

## What's inside

| Folder / file | What it is |
|---|---|
| `slides/` | The slides. Open `slides/index.html` in your browser. |
| `notebooks/` | Two Jupyter notebooks: `problem1.ipynb` (setosa vs versicolor) and `problem2.ipynb` (versicolor vs virginica, polynomial features, overfitting). |

**The slides need no installation**: just open the `.html` file.

## Set up (once)

Tested with **Python 3.13**.

1. Get the files: `git clone <this repo's URL>`, or on GitHub click **Code → Download ZIP** and unzip.
2. Open a terminal **in this folder** and create a virtual environment:
   ```
   python -m venv .venv
   ```
   (On macOS/Linux you may need `python3` instead of `python`.)
3. Activate it:
   - Windows: `.venv\Scripts\activate`
   - macOS/Linux: `source .venv/bin/activate`
4. Install the libraries:
   ```
   pip install -r requirements.txt
   ```

## Run the notebooks

With the environment active, **in this folder**, run:
```
jupyter lab
```
Then open a notebook from the `notebooks/` folder. While JupyterLab is running, the **"Problem 1"** and **"Problem 2"** buttons on the last slide open the notebooks directly. If a button does not work, open the notebook from JupyterLab's file list.

- **Iris**: comes with scikit-learn.
- **Made-up data** (overfitting, in `problem2.ipynb`): generated by the notebook itself.
